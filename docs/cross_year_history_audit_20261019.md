# 跨年同日期历史：描述性检查与固定配置增量探针

本检查只使用2015–2022小时数据、已有LightGBM开发预测和当前状态。2023–2024不评分，冻结TE_full不修改。没有开启新的完整训练。

问题：去年/前年/前三年同月同日同起报小时的24小时价格曲线，能否提供超出近期72小时与当前状态的预测信息？“价格相似”与“加入历史后有增益”分开评价。

## 预先固定的比较

1. 在2018–2022的逐小时72→24任务上，比较前一天、前三天中位曲线、前三个同星期日中位曲线、去年同日期、前三年同日期中位曲线、前三年相近日期且同星期中位曲线。
2. 同星期年度候选为同日期前后最近的同星期日，偏移限±3天。另检查年度曲线用当前72小时均价对历史72小时均价作水平校正后的效果。
3. 所有朴素比较共用样本；闰年2月29日无前三年同月同日对应时排除；要求完整72小时前序数据、完整24小时标签与历史窗口成熟。按地区和年份报告MAE、日内形状相关及尖峰数量，不以相关性当增益。
4. 专门画出三个地区2015–2022年11月11日的24小时价格及去均值形状；只是一个说明案例，不按其表现决定结论。

## 固定增量探针（不是新Full或正式SOTA）

- 每地区seed2026，使用冻结LightGBM的后续样本外预测。
- 拟合：2022年7–9月，完整标签可用时间严格早于10月1日；评价：10月、11月分别报告。
- 公共特征：当前z的15个非常数列、当前72小时均价/标准差/最后价格/最近24小时均价、前三天对应小时价格，共22维。
- annual_same_date：在公共特征上增加前三年各自对应小时价格和当时此前72小时均价，共6维。
- annual_same_weekday：增加相近日期同星期的相同6维，其他完全一致。
- 模型统一为线性残差修正：`LightGBM_q50 + clip(300*(w*x+b),-150,150)`。
- 特征均值/标准差仅用拟合段计算。目标为q50 pinball（0.5倍MAE，价格除300）加固定1e-3均方参数惩罚。
- 全批Adam、学习率0.01、固定200步、CPU float64、2线程、全零初始化。无epoch选择或超参搜索；固定最后一步与零修正仅按拟合目标选择。
- 探针的训练目标、边界、预算一致；它只检验价格历史特征的增量，不证明双场有效，也不能据失败否定非线性用法。
- 基础LightGBM不重训。历史价格可以来自其训练年份，因为它们在查询前已知；不把该模型在训练年份的残差当作合法样本外误差。

所有结果属于回顾性开发。实际数据发布时间仍依赖已有归档代理；相邻滚动预测共享标签，不能将单元数量当独立样本进行显著性推断。
