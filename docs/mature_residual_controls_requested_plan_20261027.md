## 4. 唯一下一步：成熟残差信息价值阶梯

### 4.1 可证伪问题

> 在当前 B 和严格成熟权限下，简单成熟残差校正能否同时改善 MAE 与 QS？状态匹配或双场表示是否在简单滚动残差之上提供稳定增量？

只在这个问题获得正证据后，才值得讨论 gain acceptor 或任何神经重训。

### 4.2 实验臂

记起报点为 `t`、预测步长为 `h∈{0,…,23}`、地区为 `r`，冻结树五分位预测为 `B(t,h,τ)`。正式树固定 seed 2026；B 不是三个独立神经 seed 的模型，不能复制三份当作独立重复。

成熟残差：

```text
ε(j,h) = y(j,h) − B(j,h,0.5)
```

历史起点 `j` 对查询 `t` 可见，当且仅当：

```text
j + 24h <= t
```

实验臂：

1. **B**：冻结 LightGBM。
2. **R28（唯一主臂）**：同地区、同 lead、过去 28 天全部已成熟起点的残差中位数：

   ```text
   m28(t,h) = median{ε(j,h): t−28d < j, j+24h <= t}
   Q_R28(t,h,τ) = B(t,h,τ) + β·clip(m28(t,h), −30, 30)
   ```

3. **Recent16（诊断）**：同地区、同 AEST 起报小时，最近 16 个成熟起点，对每个 lead 的原始残差取中位数。
4. **Matched16（诊断）**：沿用当前候选池权限与预筛规则（同地区、同起报小时、730 天内、完整 24 小时成熟，最多 8 个近期 + 8 个状态近邻），但直接对 `y−B50` 取中位数，不经过神经表示、历史权重或门。
5. **Full_joint（历史参照）**：直接读取现有三神经 seed 预测，不重训、不重选。

所有简单臂对五个分位共同平移，因此保持分位单调。不得根据真实价格、负价或尖峰状态进行当期路由。

### 4.3 参数与公平性

- `clip=30` 固定。
- 只允许一个跨地区共享的 `β ∈ {0, 0.25, 0.5, 0.75, 1}`。
- β 在原正式选择期 **2022H1** 选择，使用现有严格 purging 和成熟规则；不使用 2022H2 或 2023–2024 标签选参数。
- β 的选择沿用当前项目已有的 MAE/QS 守护思想：候选必须在选择期宏 MAE、QS 均不劣于 B；满足者中取两项标准化相对损失之和最小者；并列取更小 β。若没有正 β 满足，选择 β=0。
- B、R28、Recent16、Matched16 使用同一 B、同一起点、同一更新日程、同一评分器。
- Full 只作历史参照：它有三个神经 seed，而简单臂是确定性的单模型。不得把简单臂复制三份，也不得把三个神经 seed 当独立市场样本。

### 4.4 两阶段运行，避免再次直接消耗正式期

#### L0：2022H2 开发前推筛选

- 2022H1：只选择 β。
- 2022H2：β 完全冻结；记忆只因果加入已经成熟的残差。
- 这是第一阶段唯一决定性结果。

R28 进入正式回放需同时满足：

1. 2022H2 宏 MAE 与宏 QS 均不劣于 B，且至少一项严格改善。
2. 三地区中不存在任一指标恶化超过 1%。
3. 80%/90% 覆盖绝对偏差相对 B 不恶化超过 1 个百分点。
4. β>0；β=0 视为没有发现成熟残差增量。
5. 未来标签扰动、成熟边界、分位单调、β=0 精确回 B、样本对齐和来源哈希全部通过。

价格分层、季度和极端价只作诊断，不作为当期路由，也不在看到结果后改写判定。

#### L1：冻结回放 2023–2024

只有 L0 通过才运行；不得修改 β、clip、窗口、候选数或判据。

- 2023 与 2024 分开报告，再报告合并结果。
- 明确标记为**已查看时期上的回顾性前推评价**，不是盲测。
- 主比较仍是 R28 对 B。
- Recent16 和 Matched16 只回答局部性/状态匹配是否在 R28 上增加价值。
- Full 只回答复杂神经结构是否超过简单基线；其现有正式结果不因本实验重写。

### 4.5 统计口径

- 指标：MAE、QS、五个分位 pinball、80%/90% 覆盖和宽度。
- 切片：地区、年份、季度、lead。
- 机制诊断：校正绝对值、回退率、毛获益、毛伤害、净变化、错方向和有害过冲。
- 推断单位：日期，而不是重叠的 origin×horizon。
- 对每个地区构造日级配对损失向量；地区同步抽样。
- 7 天日期块为主，14/28 天为敏感性；报告配对区间，不把 seed 当独立样本。
- 价格组（负价、0–300、300–1000、>=1000）只作事后解释。

## 5. 继续、停止与简化规则

### 5.1 R28 在 L0 失败

- 不运行 2023–2024 新回放。
- 停止当前 V5 残差校正路线的新增状态门、收益接受器、尺度和事件实验。
- B 保持默认模型。
- 论文只保留协议、诊断和负结果；不能声称不存在任何条件价值，只能说在现有协议和累计证据下没有足够依据继续投入。

### 5.2 R28 通过 L0、但在 L1 失败

- 结论是成熟残差收益不能稳定迁移。
- 不用地区规则、真实价格路由或重新选 β 挽救。
- 停止 gain acceptor 与神经重训；B 仍为默认模型。

### 5.3 R28 同时通过 L0 和 L1

- R28 升格为后续研究的强制竞争基线，但不是“新模型创新”。
- 若 Recent16/Matched16 不稳定超过 R28，删除状态匹配与双场必要性的主张。
- 只有 Matched16 在两个阶段都稳定超过 R28，才说明“匹配信息”可能有增量；仍不能证明神经双场表示必要。
- gain acceptor 仍不自动启动。它至少需要：
  1. 简单校正本身已有稳定正收益；
  2. 候选收益在不用于模型选择的后续时期具有可预测性；
  3. 新的、未被反复查看的时间段可用于确认。

## 8. 论文主张边界

当前可以支持：

- Full 在现有协议下未超过同源强树；
- 位置校正是主要退化来源；
- 当前状态门、全局删除上尺度和事件只作用上尾均未通过预注册筛选；
- 历史趋势有局部价值，但复杂结构的增量价值尚未建立。

当前不能支持：

- 双场结构必要或有效；
- 状态证据门能预测校正收益；
- 事件概率、发生时间或幅度已经被建模；
- 供需因果机制成立；
- 稳定超过强树或实现条件覆盖；
- 2023–2024 是盲测；
- 三个 seed、重叠窗口或极端小时是独立样本。

如果 R28 成功，论文贡献应收缩为“严格成熟权限下的简单历史残差基线与增量审计”；如果失败，则应把本路线写成协议化负结果，而不是继续增加模型复杂度。
