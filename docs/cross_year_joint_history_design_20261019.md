# 基于跨年检查的联合历史模块建议（尚未实现）

这是对2026-10-19诊断的设计响应，不是已完成训练的模型说明。当前冻结TE_full仍为a013fd9。

## 已有证据

- 2018–2022同样本朴素比较：前三年同日期中位曲线的宏MAE58.7085，最近三天中位曲线33.2196。用当前72h水平调整年度曲线后41.1622。跨年绝对价格水平不能直接照搬。
- 同日期存在部分日内形状关联，NSW1/QLD1相关中位数约0.557/0.619，TAS1仅0.111；近期曲线关联更强。这不能证明相同日期独有的增量价值。
- 7–9月拟合的固定q50探针加入同日期特征后，10月QLD1/TAS1受益而NSW1变差；11月三个地区均变差。证据只否定“当前短期线性用法有稳定增益”，不否定可学习双场或更长训练。

## 数据与候选

1. 对查询t，候选包含过去1/2/3年的同月同日同起报小时，以及其邻近日期/同星期对照。先保留“精确同日期”身份和日期偏移，不把日期一致当成可信度证明。
2. 同时保留近期72h或近期同星期参照，并保留零历史选项，避免强迫年度历史参与。
3. 每条记录携带成熟24h曲线、之前72h观测、历史当时可用的外生状态、日历、数据覆盖掩码。当前分支使用当前72h观测、未来已知日历与起报可用外生预测。
4. 过去价格属于LightGBM训练年份不妨碍作为当前历史输入；但历史预测误差必须通过前推样本外预测生成，不能使用训练内残差替代。
5. 移除当前新库仅从2022-10开始的硬限制，按合法历史数据实际覆盖建库；把365天上限扩展到足够容纳三年候选。
6. 不沿用exp(-age/28)在年度/近期候选间直接归一化。该规则将系统性压低跨年候选，并几乎压掉两三年前的记录；应分候选组处理年龄，再由可学习状态与年龄特征决定权重。

## 共同模块与梯度路径

当前观测/外生编码 → 当前状态表示；成熟历史曲线/上下文 → 双场趋势与事件表示；两者共同进入可学习的匹配、幅度与采用模块；输出未来24h五分位校正。

- 年度参考先分离历史价格水平与日内形状；当前价格水平由当前信息和基础预测决定。
- 趋势和事件的采用分开建模，历史事件需要当前证据支持；日历相同不自动触发历史尖峰。
- 日期候选筛选可固定为合法离散规则，候选内部的软权重、事件对齐与预测头可以设计为可微。
- 双场先进行历史重建预训练，再让最终预测的加权pinball损失共同更新历史编码、当前状态编码、匹配/采用与预测头；重建仅作辅助损失。
- 联合训练时应在批内重算被选历史的编码，不能只读取已经detach的固定缓存后声称双场参与了联合优化。
- 标准LightGBM继续作为独立训练的基础预测器；不能宣称其树结构与神经模块通过同一次反向传播共同更新。基础校正可保留冻结对照，或改成可微且受约束的层后参与神经部分联合训练。

## 时间协议与验收

每个前推折都有共同的可用信息截止点。所有标准化、超参选择、训练仅用该折验证段之前的数据；训练案例中的历史输入也不得包含该案例起报之后的真实标签。记录成熟时间与年份来源。

先扩大跨季节合法样本外历史覆盖，再检验“当前信息”“当前+近期历史”“当前+年度历史”“当前+近期+年度历史”四个同容量、同目标对照。年度历史模型还需与原始历史特征、固定平滑、学习双场比较，区分数据价值与结构价值。

要求跨开发折的趋势和事件贡献可重复，不能只展示某个月或训练内成绩。最终评价前冻结架构；已查看的2023–2024只能称回顾性最终评价，不能恢复盲测资格。

当前结论：年度同日期可以作为待检验候选源，但没有证据支持把它作为必用模板；是否值得纳入最终Full，需要上述联合、跨时期比较决定。
