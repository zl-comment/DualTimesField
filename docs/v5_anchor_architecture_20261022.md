# Anchor 结构与训练耦合对照：运行前协议

分支 `research/v5-anchor-calibration-fix`，继承首轮平衡损失筛选的时间协议。
本轮回答：失配是否更符合位置/尺度共享、联合训练耦合或校正头容量不足。
这是六轮、单神经种子的开发筛选，不是收敛实验或独立盲测。

## 六个对照

| 名称 | 唯一主要改动 | 训练预算 |
|---|---|---|
| balanced | 原 32→24→2 校正头，当前平衡损失 | 联合训练 6 轮 |
| identity_anchor | Anchor 恒等为 B，校正头冻结 | 历史分支 6 轮 |
| location_only | 原校正头的位置输出保留，尺度输出恒为 0，即 s=1 | 联合训练 6 轮 |
| separate_heads | δ、s 各用独立 32→12→1 头，共享状态编码器保持不变 | 联合训练 6 轮 |
| staged | 原结构；先训练 Anchor，再冻结校正头及共享编码器 | Anchor 3 轮 + 历史 3 轮 |
| wide_head | 仅将校正头隐藏宽度从 24 增至 48 | 联合训练 6 轮 |

全部激活仍为 GELU，校正输出末层零初始化；新头使用独立随机数上下文，
其他模块同 seed 初始参数逐位匹配。原校正头 842 参数，独立双头 818 参数，
宽头 1682 参数。位置校正组保留原参数布局，但屏蔽尺度输出，其无效输出参数
不应被解释为有效容量。独立头没有拆分共享编码器，不能排除编码器层面的耦合。

所有联合/历史训练使用相同 balance_loss 和原权重、AdamW(lr=.001,
weight_decay=1e-4)、梯度裁剪 5、batch=16，seed=2026，CPU 每进程 2 线程。
本轮 identity_anchor 也使用 balance_loss；第一轮 identity 使用旧损失且仅 3 轮，
因此不能将两轮的 identity 结果差异归因于训练轮数。

staged 前三轮只允许 state 与 calibration 更新，损失固定为：

```
PB(Anchor,y)/300 + 0.5*MAE(Anchor50,y)/300
  + 0.01*mean(((Anchor-B)/300)^2)
```

固定采用第三轮末状态，不在预训练阶段挑选检查点。第四轮开始冻结 state 与
calibration，重新建立 AdamW，仅训练历史相关参数；使用共同 balance_loss，
其中 Anchor 损失是常量。记录冻结参数哈希及固定输入的 Anchor 输出一致性。
staged 只在第 4–6 轮进行最终检查点选择，其余组在第 1–6 轮选择。
总数据遍历次数相同，但分支更新次数、优化器重置、选择机会不同；这是训练
流程的整体对照，不能独立证明某条梯度通路是根因。

## 固定数据与选择

复用三个地区 NSW1/QLD1/TAS1 的 21 个认证 OOF bundle。2021 折训练
2018–2019、选择 2020、开发评估 2021；2022 折训练 2018–2020、选择 2021、
开发评估 2022。严格清除跨阶段 24 小时标签重叠。全部禁止载入 2023 及之后。
2022H2 的底层树按已有时间前推日程使用成熟的 2022H1 选择标签；不能称整个
系统在 2022 年开始前冻结。神经检查点和收缩 alpha 在开发评估前冻结。

沿用 screen 时间戳采样：训练每天一个 origin、轮换 24 小时；选择/评估每天
四个 origin、轮换六小时起点。完整历史库不抽样。固定树 seed=2026，不重训树。
每个地区×折×方案保存 raw（选择期 Full QS 最小）及 guarded（共同 alpha
属于 0/.25/.5/1，Anchor/Full 的 MAE 和 QS 不差于 B，Full 至少一项改善）。
无合格正 alpha 就回退 B。所有 36 次拟合与选择完成后才开始开发评估。
并行仅按地区/折拆任务，不改变每个任务的初始化或批次顺序。

## 预先固定的结果解读

报告两年各自三地区等权宏 MAE/QS、完整地区结果、Anchor→Full 分解、bias、
覆盖率、春季、季度、预测价格带以及 2022H1/H2。raw 与 guarded 分开比较。
从 raw 选中模型的预测另外报告 δ=A50−B50 的均值/绝对均值及区间宽度比
(A95−A05)/(B95−B05)，分母为零的单元排除并记数；这些指标不参与选模。

每个候选分别检查两个年度的 guarded：宏 MAE/QS 同时不差于 B 和 balanced，
每年至少一项宏指标严格优于 B，各地区全年及春季 MAE/QS 均不差于 B。
相对容差沿用 1e-7。全部满足才标记该候选“开发筛选通过”；不依据排名自动
替换正式流程，不按结果改权重、改 alpha、延长某一方案或挑选某个年度。

机制线索另用 raw 的同规则比较：某项改动只有在两个年度的宏 MAE/QS 均不差
于 balanced，且每年至少一项严格改善，才记为跨年一致线索。它仍不是因果
确证或统计显著。容量组失败不能证明更大模型永远无效；成功也可能来自不同
优化动态。固定 Anchor 组有效只说明当前校正可能拖累，不证明最优校正为零。

若没有方案通过，照实报告失配未解决，保留所有预测、训练曲线及选择记录。
后续全量、多种子确认需使用新的运行目录并明确仍属于开发研究。
