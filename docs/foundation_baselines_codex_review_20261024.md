## 发现与修复

1. **候选表统计口径错误**：新模型 `*_std` 曾是地区间标准差，旧主表是各 seed 地区宏平均的样本标准差。已统一为后者；地区表均值列统一为 `*_mean`。重新生成候选表，均值与预测未改变。
2. **审计汇总未强制验收**：缺少模型审计、缺格、失败/缺失重放也可能生成成功汇总。新增拒绝逻辑，候选报告生成前必须通过汇总门槛。
3. **分块核查不足**：原独立审计未实际调用 SHA 台账验证，也未检查完整行号覆盖。补充分块 SHA、顺序及覆盖核验，并补算 QS、区间覆盖率/宽度与交叉率。
4. **跨 P/Q 样本对齐盲区**：保留分表评分，同时核对不同表之间的时间戳、标签与输入/预处理元数据。
5. **审计运行入口滞后**：审计/报告 CLI 曾进入冻结的旧源码快照，无法使用后续审计修复。改为当前审查代码，模型实验冻结快照仍由原框架核验。修复 report 位置参数重复传递；收尾脚本审计失败立即退出，不继续生成成功报告。添加耗时重放阶段的实时消息。
6. **抽样参考地区不稳定**：从集合任取改为排序选择，避免跨进程随机换地区。已有重放证据保留其原 reference_cell，不重写。
