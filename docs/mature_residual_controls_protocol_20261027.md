## 3. 信息权限和固定实验臂

起报点记为 t，lead 为 h∈{0,…,23}，分位为 {0.05,0.10,0.50,0.90,0.95}。原始成熟残差为：

`epsilon(j,h) = actual(j,h) − B(j,h,0.50)`。

候选历史窗口仅在 **j+24小时≤t** 时可见。该权限要求整个 24 小时窗口成熟，不按 lead 提前释放部分标签。

| 臂 | 固定定义 |
|---|---|
| B | 当前阶段原树五分位预测，不校正 |
| R28，唯一主臂 | 同地区、同 lead，所有满足 `t−28天 < j` 且 `j+24小时≤t` 的起点残差中位数 |
| Recent16，仅诊断 | 同地区、同 AEST 起报小时，最近最多 16 个成熟起点的逐 lead 原始残差中位数；不新增额外回溯天数限制 |
| Matched16，仅诊断 | 原 HistoryStore 候选权限与预筛，直接对选中候选的原始残差取逐 lead 中位数 |
| Full_joint，历史参照 | 对齐上述查询样本的原保存预测，不重新拟合或选择 |

所有简单校正均为 `Q = B + beta × clip(median, −30, 30)`，对五个分位共同平移，不改变分位顺序，不排序补救错误。没有候选时中位残差置零并保留回退标记；β=0 必须逐位、原 dtype 精确返回 B。

R28 的 28 天左边界严格排除等号；不能误用旧 HistoryStore 统计量的包含左边界实现。Matched16 的 730 天左边界则沿用旧实现，包含等号。固定 AEST UTC+10，同起报小时等价于 origin 模一天相同。

Matched16 精确保留旧预筛：同小时、`t−730天≤j≤t−24小时`；先取最近最多 8 个候选并按时间升序保留，再按 z 的维度 `[1,2,3,6,7,8]` 在 24 leads 上的平均平方距离稳定排序补足最多 16 个，去除已选 ID。距离运算保持原 FP32 dtype 和稳定并列顺序。既不使用神经表示、历史权重或门，也不使用 query 标签选择候选。

保存每起点中位数、实际校正量、候选全库索引 ID、年龄小时数、折编号、数量与空池回退标记；填充 ID 为 −1。索引映射与有序来源库一同留存。查询真实价格、负价/尖峰组只用于事后评分，不作当期路由。

## 4. 唯一共享 β 的选择

β 网格固定为 `[0,0.25,0.5,0.75,1]`，clip 固定为 30。只用 R28 在 **2022H1** 选择一个跨地区共享 β，Recent16/Matched16 原样复用，禁止为诊断臂、地区、年份或价格组另选 β。

查询范围为 AEST 2022-01-01 起，且 **origin+24小时 < 2022-07-01 00:00 AEST**。这沿用项目严格折末 purging；等于截止点也剔除。选择函数拒绝混入 H2、其他年份或跨截止边界的查询。正式来源每地区预期 4320 个选择起点。

先对每地区完整选择样本计算 MAE、QS，再对地区等权取宏平均。候选必须同时满足：

`macro_MAE(beta) <= macro_MAE(B) + 1e−10`

`macro_QS(beta) <= macro_QS(B) + 1e−10`。

可行者中，最小化 `macro_MAE(beta)/macro_MAE(B) + macro_QS(beta)/macro_QS(B)`。包含 β=0；目标值距最小值不超过 `1e−12` 只视为数值并列，取较小 β。没有可行正 β 时返回零。若 B 某损失为零，则该项 0/0 定义为 1，正数/0 不具有有限可选目标值；不通过人为分母平滑创造收益。

保存全部 β 的各区/宏指标、可行性、标准化目标、选中 β、选择起止时间与 purging 规则。`1e−10` 为绝对数值比较容限，`1e−12` 为目标数值并列容限，均不表示统计非劣界。

## 5. L0：2022H2 唯一决定性前推筛选

β 冻结后，用 2022-07-01 起至 `origin+24小时 < 2023-01-01 00:00 AEST` 的查询评价。每地区预期 4392 个起点。记忆按相同成熟规则因果加入 H2 中已释放的残差，不重新拟合参数。

唯一进入判定的比较是 R28 对 B；Recent16、Matched16、Full 和置信区间均不能代替或改变判定。所有条件须同时满足：

1. β>0。
2. 宏 MAE、QS 均不劣于 B（绝对数值容限 `1e−10`），至少一项改善超过 `1e−10`。
3. 每地区的 MAE 和 QS 均不超过 B 的 1.01 倍（另加数值容限 `1e−10`）。
4. 每地区 C80、C90 与 0.8、0.9 的绝对偏差，相对 B 的恶化不超过 0.01（另加数值容限 `1e−10`）。
5. 三地区完整且非空，全部 11 项完整性检查通过。

完整性键名与评价模块常量一致：`source_hashes_verified`、`baseline_archive_reproduced`、`samples_aligned`、`candidates_independently_verified`、`future_labels_invariant`、`maturity_boundary_verified`、`purge_verified`、`quantiles_ordered`、`beta_zero_exact`、`deterministic_simple_arms`、`old_files_unchanged`。缺失项不得默认为通过。

真实完整性验证包括预定探针的候选集合独立逐项复算，以及将当前、未成熟和未来标签扰动后预测不变；不能仅把单元测试通过当作实际来源、成熟性和哈希已核验。

任一条件失败：记录 `stop_current_v5_residual_route`，不运行 L1；B 保持默认模型，停止当前路线新增状态门、收益接受器、尺度和事件实验。保留全部诊断和反向结果，不改参数、地区规则或判据挽救。

## 7. 评分、统计与主张边界

使用 FP64 评分：MAE、`QS=2×五个分位pinball均值`、五项原始 pinball、80%/90% 覆盖和宽度；报告校正绝对值、空池回退率、毛获益、毛伤害、净变化、错方向与有害过冲。毛获益为 `mean(max(B损失−候选损失,0))`；毛伤害方向相反，净增量为毛伤害−毛获益。
