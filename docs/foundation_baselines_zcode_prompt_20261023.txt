一、研究目标与本轮范围

研究目标：在同一电价预测任务下，比较表格预训练模型、时序预训练模型、已有任务训练模型和电价专用模型。回答预训练与时序结构是否带来稳定收益，以及外生变量的接入方式、概率校准和计算成本有什么影响。验收不以超过 LightGBM 或我们的 Full 为条件。

当前正式主表已有 15 个静态基线，包括 PatchTST、TimeXer、GateTS、DLinear、NHITS-QRA；不是没有时序模型。缺口是现代预训练基础模型。现有 PriceFM 是从头训练的单区域结构适配，不能替代预训练基础模型对照。

本轮依次实施四个独立模型条目：
  A1. tabpfn_v3：固定第三代本地回归权重，表格基础模型，保留原生分布/分位输出。
  A2. chronos2_zeroshot：固定 amazon/chronos-2，优先接入公共外生变量，冻结权重推理。
  B1. moirai2_zeroshot：固定 Salesforce/moirai-2.0-R-small，原生能力与输出范围如实登记。
  B2. timesfm25_xreg：固定 google/timesfm-2.5-200m-pytorch，核实并使用官方 XReg 外生适配路径。

A1/A2 为首批交付，完成后继续 B1/B2。一个模型阻断不应阻止另一个模型继续。
以上 ID 是拟新增 ID，不表示目前已经注册或可运行。名称必须匹配最终执行方式；例如 Moirai 仅能接收价格历史时改为 moirai2_zeroshot_price_only，并同步重命名目录与配置，不得用完整外生模型名称掩盖输入限制。
TabPFN-v2 的版本对照、TabPFN-TS、Chronos-2 微调、NBEATSx/TFT、Mitra、其他新版本仅列为后续，不在本轮自动扩张。采用 TabPFN-3 是为了先建立本地表格预训练对照；它与论文中的 API/Plus 版本是否相同必须核查，不宣称完整复现其论文成绩。

六、阶段、时间与信息隔离

1. train 标签只用于已声明的上下文/任务拟合；selection 只用于预先列出的配置选择；calibration 只用于明确登记的校准器；test 标签仅由公共评分器读取。
2. 本轮基础模型固定官方权重及一组配置，不做 HPO，不因为看过 test 误差而更换版本、样本量、协变量映射或尾部分位规则。
3. 给预测 adapter 的对象只包含合法 inputs、origin/target 时间戳及必要的冻结变换元数据，不包含 actual/target，也不提供可绕过边界的测试标签路径。调度器在预测完成之后单独加载标签评分。
4. 可以使用测试期内、在当前 origin 前已经观测到的 72h 价格历史；这是公共输入，不等于允许用测试标签持续更新模型。不得把 selection/calibration/test 中成熟标签追加进 TabPFN 的训练上下文库，也不做在线残差更新。
5. 同一原始时间序列的不同预测起点不能拼成一个共享注意力/检索组：后一个起点的历史可能包含前一个起点的未来。每个 origin 独立建样本和 group，不跨 origin、跨地区共享上下文。防止官方 cross-learning/group 默认行为造成泄漏。
6. 原生 DataFrame/数据集接口不得看到整段测试目标，再由框架内部自动滚动切片。只传该起点的历史与当时已知未来协变量。
7. 对每个模型验证单个 origin 推理与不同 batch 分组/重排结果一致（按预先设定数值容差或绑定 origin 的固定采样 RNG）；不能因同批包含未来 origin 而改变较早预测。
8. 预训练 checkpoint 发布晚于 2023—2024 测试期，需要单列预训练来源审计。记录真实数据集、时段、NEM 重叠证据及未知项；发布日期晚不等于已经证明污染，资料不足也不等于证明无污染。
9. 不为本轮临时改到 2025/2026 测试或扩展到 168h。若需要新时间轨道，单列后续方案；不能与当前主表直接混排。

七、模型逐项实施要求

A1：TabPFN-3
  - 采用官方本地 tabpfn 回归实现及明确的 V3 权重。不要使用不指定版本的默认构造器；当前官方默认可能是 3.5。库包版本不是模型代际。
  - 原始输入先由公共 flatten_inputs 构建完整 1465 列，保留所有公共块。按 horizon 建 24 个回归任务或使用经验证的等价原生接口，不能无说明把 24 个 horizon 混成一种任务。
  - 阶段0核实实际 V3 回归权重、依赖、样本/特征限制、原生 quantile/CDF 接口和显存成本。文档标称上限不等于本机同时容纳这些行列的能力。
  - 上下文样本只能来自 train。优先使用全量 train；若必须子采样，先在 train-only 性能预检中确定固定样本数和确定性按时间分层的无标签抽样规则，冻结索引与 SHA256。抽样规则不能按 test 分数挑选，也不能悄悄只取最近一段。
  - 样本量不足时在模型 ID/配置/metadata 中标识 ctxN，并进入“训练上下文受限”对照组。训练上下文量与全量拟合模型不同，不宣称等训练数据量。不要通过静默删特征、PCA、加外生预测头来绕过能力限制。
  - 预测标准化目标还是原始 RRP 必须明确，输出只逆变换一次。点评分用真实 q50，不把 mean 当 median。
  - 保存 label-context、各 horizon 模型状态/可重建清单、集成配置与 seed 语义。测试 query 不能参与全局 scaler 拟合或被当作带标签支持集。
  - 已有合法本地访问凭证可使用，但不得在日志输出 token。需要用户自行完成账号授权时记录精确入口和缺失项，继续不依赖授权的模型。不要自动改成收费 API 或上传研究数据。

A2：Chronos-2 zero-shot
  - 使用官方 Chronos2Pipeline 和 amazon/chronos-2 的固定 revision；冻结权重，明确无微调。不是 Chronos-T5、Chronos-Bolt 或 synth/small 变体。
  - 逐项列出七块输入到历史目标、past-only covariates、known-future covariates、当前上下文的映射。区分“历史实际需求”和“当时的未来需求预测”，不要未经说明把它们当同一统计变量拼接。
  - 对只在未来存在的协变量，必须验证该版本支持的缺失历史与掩码语义；不伪造历史数值，也不能用其他 origin 的缓存拼接一条全知预报序列。
  - 显式 prediction_length=24、公共 context=72；默认最长 context 不应扩大信息范围。只允许官方必要 padding，并记录 mask，不添真实额外历史。
  - 直接核实原生输出是否支持五个指定分位，保存原始分位顺序及来源。支持参数不自动证明尾部分位由模型原生提供，要检查官方实现如何生成。
  - 七块信息无法合法映射时给出具体缺失字段，保留 price-only 或受限 covariate 版本作为补充对照；不要训练自制 adapter 后仍叫 zero-shot。

B1：Moirai-2 zero-shot
  - 固定 Moirai 2.0 权重，不能把 Moirai 1.x 或 Moirai-MoE 改名成 2.0。
  - 在锁定版本上实测 covariate 支持、patch/padding、输出分位集合；不能套用 Moirai 1.x 接口能力作为 2.0 的能力证明。
  - 若原生只给 q10—q90，而不支持 q05/q95，不能外推、复制端点或补高斯尾巴冒充完整五分位输出。可将原生 q50 进入 P 表，其他原生分位进入明确标注的辅助表；说明未进入 Q5 表的原因。
  - 官方有合法完整分布/采样输出时，可以按预先固定算法提取公共五分位，明确 MC 样本数、精度、RNG 和开销。
  - 输入受限时使用说明限制的模型 ID/目录，保留模型真实性；不换普通 MLP 或额外训练头来强行凑齐。

B2：TimesFM-2.5 + XReg
  - 明确加载 google/timesfm-2.5-200m-pytorch 和官方 2.5 实现；当前仓库也有 3.0，不能跟随默认版本漂移。

  - 若 XReg 按每个 origin 的合法历史拟合，限制到相同 72h；未来 covariates 仅在未来预测中使用。全局 XReg 参数只能由 train 拟合。
  - 核实官方 XReg 需要历史和未来同时存在的字段。当前缓存只有未来预测的字段不得通过编造历史补齐。
  - 核实连续 quantile head 是否真实支持所需分位，以及 XReg 位置回加如何作用于所有分位；原生 point、mean、median 不得混用。
  - 如果只能得到点输出，则进 P 表；可以保留原生模型与公共输入的受限适配结果，但明确它不能进入完整同输入 Q5 比较组。

八、输出、三 seed 与预算口径

复用 make_prediction_artifact/save_prediction_artifact/load_prediction_artifact/score_predictions。
Q 表：原价 RRP 的 [N,24,5]，分位 [.05,.10,.50,.90,.95]。保存重排前输出，由公共评分器计算交叉率，再重排取 q50 计算 MAE/RMSE。
P 表：原价点预测 [N,24]；没有合法完整分位时不得复制五列或借用其他模型区间。
QS5=2×五分位平均 pinball，不称精确 CRPS。报告 MAE、pooled RMSE、QS5、各分位 pinball、80/90%覆盖和宽度、交叉率。P 表缺失的概率指标为缺失，不填零。
不根据本数据范围裁剪价格、实际值或预测来改善评分。官方权重/原生分布若本身具有有限支持或内置截断，记录其原生行为；新增裁剪禁止，诊断中记录超界/饱和率。非有限值明确失败，不静默修补。
每格完整保存 origin_unix、target_time_unix、原始实际值、公共哈希、输入范围标签、权重与配置哈希、预测来源。

seed=2026/2027/2028 仍各自评估；先按 seed 求三地区等权均值，再报告 seed 均值与样本标准差，不先平均预测。
冻结确定性模型的三 seed 可能完全相同。必须说明 seed 控制的是抽样、模型集成还是没有随机作用；不能把相同权重的三次推理称为三个独立训练。可去重计算但保留 cache/reuse_of 和确定性复核证据，不能伪造独立检查点。
最多四个默认模型共 36 个逻辑评估格，不等于 36 次独立训练。重命名或受限作用域不会凭空增加一个额外模型；所有计划变更在正式测试前冻结。外部阻断必须在完整计划清单中保留。

第一轮只做固定配置，不调参。对每个模型先用 train/selection 的输入做有限的内存和速度预检，确定 batch、精度与上下文方案；配置冻结后才打开 test 标签评分。
预算记录至少包括加载/上下文拟合/推理时间、总墙钟时间、峰值 CPU/GPU 内存、CPU/GPU 型号、实际行数、特征数、batch、精度、采样数、集成数、权重大小及每千 origin 吞吐。预训练计算成本与本地任务成本分开，不能宣称与从头训练模型等总算力。
OOM 先降低推理 batch、顺序执行 horizon 或使用官方缓存/offload；不能跳过困难样本、自动减少公共历史或换小模型却保留原 ID。若必须改算法相关参数，另建配置与运行，保留失败记录。

九、验收与执行顺序

阶段0：来源、能力与公平性审计
  读取父缓存并核验 shape/hash；只用 train/selection 做 API 和小样本检查。输出 docs/foundation_baselines_stage0_20261023.md 和机器可读能力表。
  每模型列明本地权重访问、实际版本、全部输入映射、原生分位、上下文限制、预训练来源、依赖、估计完整运行成本、可进入 Q/P/受限输入/上下文受限的哪一组。
  对未知项附可复查错误或官方证据，不用“已支持”占位。

阶段1：公共接入与模型目录
  实现第二批注册、配置验证、阶段隔离、冻结快照、可恢复 worker、进度和报告能力。
  旧第一批矩阵、模型 ID、schema、训练预算、冻结运行保持原语义；不要通过放宽所有校验让新方法过关。
  配置和 manifest 显式记录 fit_requires_train_labels、selection_use、calibration_use、weight_training、output_type、input_scope、seed_scope、pretraining_scope 等等价字段。
  实现下载后可离线重放；运行中不得自动更新官方依赖或权重。某个可选包未安装不能阻止其他模型 import/运行。

阶段2：有意义的验证与小规模运行
  - 对真实官方权重/库至少一次验证适配前后输入与预测对应关系，只有 mock 或随机模型 smoke 不算官方接入验收。
  - 变动 evaluation actual/target 不影响模型状态或预测；预测 adapter 访问这些字段必须失败。
  - 逐块核验输入映射和 mask；不能把“接收了 dict”当作使用了所有信息。扰动测试结合映射检查，不要求每次扰动必然改变模型预测。
  - 对原价逆变换、时间戳秒单位、horizon 顺序、分位 level 顺序、mean/median 和负价进行验证。
  - 对跨 origin 隔离、batch 顺序、独立/批量推理、seed 重放和官方跨序列注意力分组进行因果性测试。
  - 人为改动缓存、权重 revision、上下文索引、输入 scope 或配置，应使恢复/汇总校验失败，而不是复用旧结果。
  - 验证断点续跑不重复拟合、不遗漏行、不混合不同快照；耗时长的模型要可按 origin 分块持久化和恢复。
  - 检查旧公共输入/评分、第一批目录/调度/报告的相关回归。按实际改动运行必要测试，不用测试数量替代证据。
  - 真实权重 smoke 使用开发数据，输出完整 metadata 并标 smoke，不能进入正式主表。

阶段3：正式评估与独立复算
  每个模型通过阶段2后冻结源码/配置/权重/上下文索引，按声明的完整三地区三 seed 运行，不等所有其他模型解除外部阻断。
  新 run_root 使用独立名称，例如 outputs/forecasting/foundation_baselines_20261023_<批次或模型>，不要写回父运行。
  产物重新用公共评分器逐格复算；检查 sample/time/actual/preprocessing/input 哈希，并检查语义作用域与模型权重身份。
  对完整确定性输出可做全量重放；对昂贵输出至少固定覆盖头/中/尾及极端价格样本做重放，报告抽样范围、容差和差异，不把抽样一致称为全量逐位一致。
  比较范围按信息和输出能力明确分组：完整公共输入 Q5、完整公共输入点预测、输入受限、训练上下文受限、预训练来源待确认。作用域可多标签，不能伪造同一 input_hash 来掩盖实际删输入。
  预训练模型同样本分数可列候选对照，但预训练重叠未知时必须显式标注，不宣称严格无污染的新盲测。
  当前 Full_joint 额外使用成熟历史误差，信息范围不同；在候选报告中保留这一标签，不能因新模型加入而把旧 Full 行变成等信息对照。

模型已编码、smoke 已通过、正式9格已完成、独立复算已通过是不同状态，逐项报告。
一个模型不支持 q05/q95 或完整公共外生时，按真实能力交付补充结果，不为取得主表资格伪造分位/输入。
