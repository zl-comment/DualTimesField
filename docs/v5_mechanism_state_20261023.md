# 供需状态下校正证据不稳定：问题、假设与验证协议

## 已观察的问题与尚未证实的解释

此前正式输出的事后诊断发现：QLD1 的 Anchor 位置校正增加绝对误差，历史分支只挽回
部分损失；区间收窄同时降低覆盖。普通价和负价时段累积了主要 MAE 损失。
2021/2022 限幅开发实验改善种子均值，但并未通过所有 seed 的稳定门槛。
这说明“校正幅度需要受到约束”值得研究，不证明供需状态是唯一原因。

本轮待证伪问题：**在相似供需与输电状态下，历史树残差的校正方向缺少跨时间一致性，
或样本支持不足时，统一幅度的 Anchor 是否仍允许了缺少证据的校正？**
拟解决的是校正可靠性与状态条件失配；MAE/QS 是问题是否得到解决的结果证据。
不能把实验后的指标改善倒写成事前根因，也不能仅凭设计宣称论文首创。

## 固定状态与证据计算

所有状态只使用原七块输入已经包含的量：备用容量、净负荷（demand50−UIGF）、
进口余量、出口余量，以及 predispatch/interconnector 覆盖标记。没有新增天气或新闻。
OOF 折标准化不同，不能将其 z-score 混作 MW；从同一 vintage 档案读取原字段，
逐折验证其与已归档输入的对应：线性通道检查正向仿射，净负荷重放原训练标准化和
可逆 log 软饱和。验证不拟合新的预测参数，也没有恢复被硬裁剪丢弃的信息。

每个地区、开发折独立，仅用神经训练期拟合阈值，不用选择年/评估年的标签或分布：

- tight：备用容量低于训练 q20，同时净负荷不低于训练 q50；
- tight_import_limited：上述条件并且进口余量低于训练 q20；
- surplus：净负荷低于训练 q20，同时备用容量不低于训练 q50；
- surplus_export_limited：上述条件并且出口余量低于训练 q20；
- ordinary：其余已覆盖状态；uncovered：任一覆盖标记为零。

这是相对市场状态代理，不是真实拥塞绑定判定，也不把 surplus 当作已知负价。
只使用原始价格分组诊断问题，绝不将当前真实价格用于预测时分组。

将训练起点按 AEST 唯一日期分为四个连续、大小尽量相等的时间块。在每个状态/块中：

1. 位置证据为原树样本外残差 `median(y−B50)`；
2. 下尺度证据为移除该位置偏差后，低于 B05/B10 的频率相对 .05/.10 的平均偏差；
3. 上尺度证据为移除该位置偏差后，高于 B90/B95 的频率相对 .10/.05 的平均偏差。

三者各自取跨块方向一致度 `C=|sum(v_j)|/sum(|v_j|)`；分母为零则 C=0。
支持度 `S=n_min/(n_min+30)`，n_min 为四块中最少的有该状态的起报日期数。
门值 `g=S*C`，uncovered 三门值均为零。日期计数只避免把 24 个预测步当成 24 个
独立支持样本；滚动窗口仍相关，S/C/g 都不是置信概率、显著性或因果识别结果。
同向但很小的信号也可能具有高 C，因此不能解释为效应大小或保证收益。
阈值、四块与 30 日期常数一次性预设，不在本轮搜索。

## 唯一模型改动：状态条件下的三个幅度约束

保留此前 bounded 的头、所有可训练参数、损失与历史模块计算：

`δ = g_location * 30 * tanh(150*tanh(d)/30)`

`s_lower = 1 + g_lower * .1 * tanh(.5*tanh(l)/.1)`

`s_upper = 1 + g_upper * .1 * tanh(.5*tanh(u)/.1)`

门值为固定训练统计，不引入新可训练参数。只限制幅度，不强制位置修正的正负。
约束后的位置继续进入原历史耦合公式；绝不能只在 forward 最后替换 Anchor、
却继续用未约束的位置计算历史修正。三门为零只保证 Anchor 回到树，Full 仍有历史修正。
这些乘法也改变初始有效梯度，不能称为与旧模型优化过程完全等价。

三个配对训练臂：

| 臂 | 目的 |
|---|---|
| bounded_reference | 原统一 ±30 / [.9,1.1] 限幅 |
| constant_evidence | 每头使用状态门在训练已覆盖单元上的加权平均，缺失仍为零 |
| state_evidence | 按当前可获得的状态使用对应的三门 |

constant 与 state 的三个门在训练集的平均值完全匹配。评估期分布改变时，平均门值
可能不同；不能拿评估标签再匹配收缩强度。这个对照用于区分状态分配与整体收缩，
并不保证两个臂训练后实际位移幅度相同。

## 先证据诊断，再确认机制

第一阶段不重新训练神经模型：冻结六份训练策略后，在已有 bounded 的 2021/2022
raw/guarded 输出上按上述状态报告校正伤害、获益、位置跨越目标、区间宽度和覆盖。
预设弱位置证据为 `g_location <= .25`，同时报告未覆盖及其余状态；若弱组没有更高
校正伤害，必须保留该反证，不能把问题解释写成已经成立。actual 只在离线诊断使用。

实现阶段运行三 seed、三臂的短流程验收，验证真实数据、梯度、恢复、冻结及评分链路；
短流程不是确认实验，不据其指标决定方法、改门槛或更新主表。

完整确认入口保留原两个开发折、三地区、三个神经 seed、树 seed 2026、七 OOF、
全小时、每臂20 epochs、batch128、AdamW .001/wd1e-4、clip5、FP32网络/FP64历史。
共54次物理训练，不重复此前四方案。统一原年度聚合 checkpoint/alpha 选择，
不使用已失败的 multiwindow 规则，不增加门值搜索。所有54次选择冻结后才评估。
2021/2022 已反复用于开发，2023/2024 已事后诊断；均不能称为新盲测。

保留旧 MAE/QS 宏/区域/春季及每 seed 门槛，同时比较旧 asymmetric 和本轮 bounded。
机制证据单独报告：弱证据组的校正伤害是否降低、获益是否同时消失、区间收窄是否受控，
以及 state 是否优于同等训练平均收缩的 constant。全回退、所有门趋零、仅MAE下降
但机制假设不成立，都不足以宣称解决了所提出的问题。每个状态必须报告样本量和
弱/强证据分组；状态分类发生变化时报告占比，不靠全局平均隐藏退化。

实现完成不自动启动54次训练，不自动替换正式主表。此前72次失败与最新36次训练记录保留。

## 研究定位

完整机理出清通常需要报价曲线与网络/机组约束，当前没有这些完整输入。本方法是
“供需状态条件下的残差证据约束”，不是完整物理模型，也不是给价格套供需守恒方程。
与只增加外生输入、统一 shrinkage、供需曲线出清预测之间的差别是**校正可靠性**这一问题。
是否构成新的论文贡献，需要机制实验和进一步文献核对；此处不声明首创。
