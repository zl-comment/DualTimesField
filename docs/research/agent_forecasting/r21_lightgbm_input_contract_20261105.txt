Input-operation admission procedure
1. Map each feature block to meaning, units, timestamps, publication availability,
   and training preprocessing. Reproduce default predictions without change.
2. For each proposed operation specify exact allowed cells, cutoff restrictions,
   replacement/source construction if any, preserved invariants and identity.
   All fitted replacement statistics must come from training data only.
3. Establish that an operation changes the information intended, retains valid
   time/feature semantics, and is reasonably supported by the training inputs.
   Schema-valid, causally available, and empirically useful are separate claims.
4. Evaluate admissible candidates on development data and identical mature
   historical cohorts, including adverse cases. An operator is not assumed useful
   because it can run. Reject unsupported operators instead of weakening checks.
5. Only admitted operators enter the Kev action set. Log operation provenance,
   input hashes, all forecasts, paired evidence, hypothesis and stopping reason.

At present the original unchanged input is the only established valid operation.
Potential finite, schema-preserving transformations or alternate as-of sources
are research candidates, not approved operations or implemented features.
If this checkpoint cannot support meaningful input control, document that result.
A separately trained, then frozen, input-aware LightGBM would be a distinct
predictor version and require its own matched default-input baseline. Do not
silently replace weights or bypass the existing finite-value/schema validation.

Planned control loop
Observe current available evidence -> identify a testable input hypothesis ->
decide whether an additional experiment is warranted -> choose one admitted
operation -> run the same frozen LightGBM -> compare against default/previous
inputs on a fixed mature historical cohort -> retain/revert/continue -> publish.
Do not equate the best current candidate with proof that every untested input
operation is unhelpful. Do not force revisions merely to demonstrate activity.
No future truth for the current origin is available to Kev or input operators.
