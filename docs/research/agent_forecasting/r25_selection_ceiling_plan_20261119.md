## 1. 研究问题与动机

R24 四个预注册实验证明：在冻结 LightGBM + 两操作空间上，决策层（准入、
迭代、新鲜证据、候选账本）没有可复现增值，最佳收益 0.028 QS 且区域异质
（TAS1 有余量、NSW1 历来无、QLD1 为 QS/MAE 取舍）。证据指向上游：候选
预测器质量与候选间互补性。

因此本轮回答的**不是**「完美选择器能好多少」（该量在有限样本下必然为正、
且随候选数单调增大，见 §4.5，无决策价值），而是：

> **在开发折上，一个只用起点可得信息的可实现路由器，相对「永远用
> LightGBM」能否稳定取得至少 0.25 QS（≈0.6% 相对）的区域等权改善？**

- 过不了（且不触发 §5.4）→ 关闭模型选择/路由（含 MoE 式）方向，写回顾收档。
- 过了 → 进入硬路由 / 软组合的方法开发。
- 天花板（oracle）仍然测量，但只作为「还有多少余量没被可实现规则吃到」的
  上下文与 §5.4 的触发量，不直接参与判定。

结论措辞的范围限制：本轮只比较「路由 vs LightGBM」。自研方法不重跑，
故不得外推出任何关于路由相对 Full_joint / Anchor 系的位置的结论。

## 2. 开发折定义

三折，评估期互不重叠，每折自带选择期；训练数据与**所有**超参、分桶边界、
窗口长度、准入判定一律截止于该折选择期末。

| 折 | 训练 | 选择期（估计路由规则/分桶/窗口/准入） | 评估期（判定） |
|---|---|---|---|
| A | 2015 → 2019-01-01 | 2019H1 | 2019H2 |
| B | 2015 → 2021-01-01 | 2021H1 | 2021H2 |
| C | 2015 → 2022-01-01 | 2022H1 | 2022H2 |

- 加 A 折的理由：v3 的两折（2021H2、2022H2）都是异常期（高波动 / 2022 年中
  NEM 暂停后管制定价），与 2023–24 的形态都不像；只用异常期两折做「状态
  多样性」说服力不足。A 折提供一个接近常态的市场。
- 【v4.1 改动】A 折数据可行性已由项目方在服务器核实：外生档案
  （predispatch / PDPASA / 联络线 NPZ）自 2014-12-31 起全覆盖，三折成立。
- 不用 2020H2：COVID 需求冲击期，会再引入一个异常态。此为预注册的主动
  选择，写入结果文档限制条款。
- **评估起点**：每日 4 个起点（本地 00/06/12/18），每折每区域约 736 个，
  三区域约 2 208 个/折。v3 的日频 181 起点与测试协议（小时频，17 521
  起点/区域）口径不一致，且把结论绑死在单一一天内时点。若档案协议不支持
  任意小时起点，降级为日频并在结果文档显式标注口径偏差（不得静默降级）。
- 选择期按同一起点规则生成，用于估计规则与准入，**不计入判定分数**。

## 3. 候选模型与排除规则

每个候选 × 每折 × 每区域训练（或推理）一次，对选择期与评估期各出一次预测
并落盘；**模型用完即释放，全程无常驻**。开发自研方法一律不参与。

**Tier-1 候选池（判定用）**：
- baseline_lightgbm（**3 个 seed：2026/2027/2028**；R0 取 seed 2026，三 seed
  的 per-region sd 既用于报告、也用于 §5.2 的容差公式）
- baseline_xgboost（生产超参，seed 2026）
- chronos2_zeroshot（免训练推理，受限输入）
- persistence-24h、周季节 naive（零成本）
- 算力允许时按固定优先级补：patchtst → dlinear → gatets → timexer →
  linear → mlp

**【v4.1 改动】Tier-1 准入规则（唯一的精度类排除；逐桶判定）**：
某候选在该折、该区域、**该需求状态桶**的选择期上满足
`QS_candidate ≤ 1.25 × QS_lightgbm`（同桶、同选择期）即在**该桶**进入
Tier-1；否则该桶降入 Tier-0。
- 相对 v4 的变化：带宽数字保持 1.25×（项目方默认），但作用域由全局改为
  逐桶。理由：全局带宽会把 naive 一刀切挡在池外，与"探测尖峰期 naive
  互补性"的目标相反；逐桶判定使 naive 在尖峰桶自动获准、在其余桶自动
  排除，由数据而非一个全局常数决定。
- 噪声追逐不由带宽控制，由 §4.4 的切换边际 m 控制（见该节）。
- 取代 v3 的「发表 QS > 35 机械排除」：那是用测试期发表数字给开发折候选池
  设门，既混口径，也用错判据——路由价值取决于**互补性**而非平均精度。

**Tier-0（只进 oracle 报告，不进判定）**：未过逐桶准入带的候选、
tabpfn_v3。tabpfn 恢复为候选是因为它只影响报告用天花板；排除它会无理由
压低余量估计。

**排除（保留，并标注方向）**：moirai2、timesfm25——点输出，无公共五分位，
无法算 QS；不为其套残差分位 / conformal 包装（会引入需要调参的新组件，
超出本轮范围）。所有排除的后果方向明确：**只会压低天花板**，故对「关闭
方向」的判定是保守的，对「开启方向」不构成风险。

## 4. 评分与统计报告

### 4.1 基本口径
逐起点 QS（2 × 五分位平均 pinball，24 小时平均）与 MAE（排序后 q50）；
先区域内平均，再三区域等权。所有比较均为与 R0 的**逐起点配对差**。

### 4.2 防「极端起点主导」的措施
判定仍用均值（它才是部署时的损失），但必须同时报告，任一项触发即在结果
文档标注「余量脆弱」：
1. 10% 截尾均值、中位数、IQR；
2. 逐起点胜率（配对差 > 0 的比例）与符号检验；
3. 逐日 jackknife 影响：留一天重算总增益，报告**单日最大贡献占比**，
   > 25% 即标注脆弱（并作为 G1(c) 的硬条件）；
4. 实现价格带切片（< 100 / 100–300 / > 300 $/MWh）与需求状态分桶切片的
   增益分解；
5. 增益是否集中在少数区域 / 少数月（§7 消融 5）。
（v3 只报中位数与 IQR 不足：判定量本身是均值，报一个中位数不防任何东西。）

### 4.3 不确定性与检验
- 分块 bootstrap 95% CI，**块 = 7 天**（4 起点/日下 24h 预测窗口重叠，
  日块不足以覆盖序列相关）。
- Diebold–Mariano（1995）单侧检验，HAC 方差 + Harvey–Leybourne–Newbold
  (1997) 小样本修正；仅用于 R0 vs **单一预先指定**对手。
- **oracle 与任何「取多者之优」的量不做 DM**：那是后选择推断，DM 无效。
  多候选显著性用 Hansen (2005) SPA 或 Hansen–Lunde–Nason (2011) 模型
  置信集（MCS）。
- 状态条件路由的正式说法是条件预测能力：按 Giacomini–White (2006) 框架
  报告条件检验，不得把分桶后的无条件 DM 当作条件结论。
- 消融与区域分解约 20 个比较：进入结论句的用 Holm 校正，其余明确标为
  探索性。
- 文献边界（不确定处如实标注）：上列为我有把握的经典条目。EPF 侧「DM 为
  基准协议标配」我按 Lago 等人的开放基准理解，**具体条目请自行核对**；
  简报提到的 MoiraiAgent / TimeCopilot 我未核验原文，不代为引用。组合谜题
  方向引 Clemen (1989)、Smith–Wallis (2009)。

### 4.4 参照策略（可实现，全部在选择期估计）
- **R0（基准参照）**：永远 LightGBM（seed 2026）。
- **S1**：逐区域按滚动成熟窗口选当前最优（窗口长度 k 在选择期定好，
  预注册 k = 28 天；只用起点前已成熟的真实值）。
- **S2（判定用主估量）**：区域 × 需求状态分桶硬路由，桶内最优由**该折
  选择期**决定。**分桶边界必须用该折选择期重新估计**，不得沿用 R23/R24b
  定义——那套边界在 2022H2 上调出、又直接作用于 C 折评估期，是明确泄漏
  （项目方已确认）。桶特征只用 as-of 预测需求。
- **【v4.1 新增】S2 的切换边际 m（向 R0 收缩）**：桶内改用非 LightGBM
  候选，需该桶选择期配对优势 ≥ 1 个桶级标准误（SE = 桶内逐起点配对差
  标准差 / √n_b，由选择期自身估计）；否则回落 R0。
  理由：桶内起点数 n_b ≈ 724/桶数，而含尖峰区段的逐起点配对差标准差与
  QS 水平同量级，桶均值 SE 很可能是判定门 0.25 的若干倍——桶级 argmin
  本身即高噪声操作，必须有显式信噪比门槛。
  **不确定标注**：上述 SE 量级为按起点数与已知尖峰形态的量级推断；真实
  标准差须在选择期实测并写入结果文档。若实测 SE 远小于 0.25，m 近似
  失效（不再绑定）——不影响判定有效性，但须披露。
- **S3**：Tier-1 逐分位中位数组合（另报逐分位均值、选择期 top-3 组合）。
  零参数，是组合谜题文献下的强廉价对手；一个打不过零参数组合的路由器
  没有方法学价值，故 S3 在报告中与 S2 平级，而非 v3 的"仅作记录"。

### 4.5 天花板定义（全部只报告，并作为 §5.4 触发量）
- **C1**：逐起点上帝视角最优（Tier-1 池；另出 Tier-1+Tier-0 全池版本）。
- **C2**：区域 × 月最优（事后）。
- **C1_null（关键标定，v3 缺失）**：对**同一** LightGBM 的 3 个 seed 做
  逐起点 oracle。三者是同一模型的噪声复制，其 oracle 增益全部是有限样本
  挑选噪声。报告的余量一律写成 **C1 − C1_null**；裸 C1 不得出现在结论句。
  理由：K 个候选、逐起点 argmin 下 `E[min loss] < min E[loss]`，偏差随 K
  与噪声单调增大——v3 的 G1（C1 − R0 ≥ 0.30）几乎不可能失败，是一道
  无信息的门。
- **候选相关结构**：报告 Tier-1 两两配对损失差相关矩阵与「有效候选数」
  （相关矩阵特征值谱）。同特征同管道的树/神经基线误差高度相关，名义候选
  数会严重高估多样性。

## 5. 判定门（唯一一条）

### 5.1 主估量
**S2 相对 R0 的区域等权 QS 改善 ΔQS**。

### 5.2 G1 通过条件（数字先于结果固定，三条全部满足）
- **(a) 幅度，取最差折**：A、B、C 每一折 ΔQS ≥ **0.25** 且 ≥ **0.6%**
  （相对该折 R0 的 QS）。
- **(b)【v4.1 改动】无区域重大受损（阈值改为预注册公式，撤回 v4 的裸数字
  0.30）**：任一折、任一区域
  - QS 恶化 ≤ `max(0.05, 2 × sd_QS)`
  - MAE 恶化 ≤ `max(0.15, 2 × sd_MAE)`

  其中 `sd_*` 为**该折该区域** LightGBM 三 seed（2026/2027/2028）的对应
  指标样本标准差，只由 R0 自身计算，与任何路由结果无关，故不构成结果驱动
  的门槛放松。
  **来源论证**：
  1. 0.05 锚定 R23（历史最佳）产生过的最大单区域效应 0.0508——"任何区域
     受损不得超过上一代最佳方法曾产生的最大单区域效应"。同时在区域等权下
     单区域受损 h 只贡献 −h/3，0.05 最多消耗门槛 0.25 的 6.7%，不足以让
     "牺牲一个区域换总分"通过。
  2. 0.15 = 0.05 × 尺度比 × MAE 相对噪声比。尺度比取开发折水平
     68.49/39.28 ≈ 1.74（R24b 区域等权 MAE/QS）；相对噪声比取主表
     LightGBM 三 seed 的 MAE sd 0.0147 与 QS sd 0.0049 之比（3.0）再除以
     尺度比 1.74，≈ 1.7。0.05 × 1.74 × 1.7 ≈ 0.148 → 0.15。
     **口径标注**：此处只借用测试折的**噪声比**，不借用其水平值；
     `max(·, 2×sd)` 项即为开发折实测噪声的兜底。
  3. `2 × sd` 项的含义：容差永不低于 R0 自身不可约 seed 噪声的两倍，
     避免把噪声判成"区域受损"。
- **(c) 稳健性**：7 天分块 bootstrap 单侧 p < 0.05 在 ≥ 2/3 折成立，
  且单日 jackknife 最大贡献 < 25%（§4.2 第 3 项）。

### 5.3 阈值依据与口径更正
开发折 R0/identity 区域等权 QS ≈ 39.28，R23 全部贡献 0.028（≈0.07% 相对）。
v3 把 0.30 说成"1.2% 相对"是用了测试折尺度的 24.2——同一折上
0.30/39.28 = **0.76%**（项目方已确认）。本门取 0.25 QS 并附加 0.6% 相对
条件，使阈值在三折不同价格水平下口径一致，约为 R23 收益的 9 倍，符合
"值得造新机器"的一个数量级要求。
(b) 取代历史"三区域 QS 与 MAE 同时严格改善"全区域门的理由：R24 证明该门
对保守策略结构性不可能（不行动的差恰为 0）；改为"区域等权改善 + 无区域
重大受损"保留防单区域献祭的作用，又不把一道不可能的门当作科学结论。

### 5.4 【v4.1 新增】预注册的触发式二次评估（仍属同一道 G1，不新增门）
针对"S2 失败但 oracle 残余余量大且三折稳定"的情形，预先注册**唯一一次**
重设计机会。它不是看结果再决定，而是由与 S2 评估分数无关的量自动触发。

**触发条件（四条全部满足，缺一即硬关闭）**：
1. S2 **仅因 (a) 幅度不足**而失败——若 (b) 区域受损或 (c) 稳健性失败，
   不触发（说明路由在伤害区域或依赖少数日，属于结构性否定）；
2. `C1 − C1_null ≥ 1.00` QS 且三折同时成立。1.00 = 判定门 0.25 的 4 倍，
   含义是"更好的路由器只需吃到残余余量的 1/4 即可过门"，这是对路由器
   效率的最低可信要求；
3. 有效候选数（§4.5）≥ 2.0——余量不是由高度相关的同质候选伪造的；
4. S1 / S2 / S3 中**至少一个**可实现变体在三折同时为正——信号可被只用
   起点信息的规则触及，而非纯事后产物。

**重设计的允许范围与限制**：
- 只许更换 **S2 的路由特征与粒度**（如换桶特征、改用软权重、改 k）；
- **不许**改动 G1 的任何数值与条件、不许改折定义、不许改候选池与准入带、
  不许动 Tier-0/Tier-1 划分、不许触碰评估期以外的任何新数据；
- 新规则必须在**查看其评估期分数之前**以书面预注册（只用该折选择期数据
  完成设计），并记录提交号；
- **只许一次**；第二次评估的 (c) 显著性要求收紧为 **p < 0.025**
  （二次抽样的 Bonferroni 分配），(a)(b) 不变；
- 第二次仍不通过 → 方向硬关闭，写回顾收档，**不允许第三次**。

**不触发或二次失败时的分支措辞**：若 S2（或二次规则）失败而 **S3
中位数组合**满足同一 (a)(b)(c)，结论记为「关闭选择式路由，低成本组合
作为默认路线」——这是 G1 的分支措辞，不是第二道门。

### 5.5 报告性标注（不改判定）
若 `C1 − C1_null < 0.30`，即使 S2 过线也须在结果文档标注「可用余量接近
噪声标定水平，后续方法开发风险高」。

## 6. 执行顺序与预期成本

严格串行，每一步产出落盘后再进下一步；任一步发现口径问题即停。

1. **【v4.1 改动】档案核对（半天，预期无可复用）**：核对 2019/2021/2022
   开发折是否存在可复用的静态基线预测。
   **项目方已核实：主表附注的"2021/2022 开发分数保留原档"是联合方法
   （开发方法）的开发分数，静态基线在档案中只有 test 折预测。因此
   Tier-1 预期无可复用，本步仅作核对，不计入成本节省。**
2. **最小三件套先行（早停点）**：LightGBM(3 seed) + persistence +
   chronos2，三折三区域。先算 C1_null、C1(最小集)、S1/S2/S3。
   若此时 `C1 − C1_null` 已接近 0，可提前关闭方向并停止后续投入——
   这是最省的早停点，也使最坏情况成本止于本步。
3. **补 Tier-1 其余候选**：xgboost，再按固定优先级补神经基线；算力耗尽
   即停（已跑部分照常分析，候选池实际组成写入结果文档）。
4. **Tier-0 补充（可选，仅供 oracle 报告）**：tabpfn_v3。
5. **分析**：`scripts/analyze_r25_ceiling.py` 产出逐起点分数表 → 参照与
   天花板 → 六个消融 → G1（含 §5.4 触发判定）→ 结果文档
   `r25_selection_ceiling_result_<日期>.md`。
