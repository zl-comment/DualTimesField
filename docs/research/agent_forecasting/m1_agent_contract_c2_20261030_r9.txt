Bounded reduction and counterexample
The historical 193-case corpus only has zero, one or two listed refs. The runtime
contract accepts longer listings. Append a same-body, same-vintage three-mirror
case with all three receipts before the origin: the first two canonical mirrors
return TIMEOUT and NOT_FOUND, and the third returns COMPLETE_VALID.
B/C keep their existing first-two-mirror plan and two-GET maximum; no comparator
is changed after seeing this case. D can legally LIST, FETCH_REF(third), FINALIZE_TYPED
within the same envelope. Enumerating this trace demonstrates reachability, not
that a real LLM can infer which unseen mirror will succeed.
The default 194-case corpus is explicitly finite and is not the entire input domain.
Every legal D trace within each supplied case is still enumerated; the weak-B
control still checks that the detector can find a useful difference.

Verdicts
A useful PUBLISHED_TYPED witness yields REDUCIBILITY_REFUTED. With engineering
tests passing, the gate may report ENGINEERING_PASS_REDUCIBILITY_REFUTED; without
engineering acceptance, or without a useful witness, it remains BLOCKED.
No witness in the tested cases means NO_COUNTEREXAMPLE_IN_TESTED_SCENARIOS and
INCONCLUSIVE_REDUCIBILITY, never global FIXED_RULES_SUFFICIENT_AGENT_NOT_NEEDED.
Legacy sufficiency report tokens also map to INCONCLUSIVE_REDUCIBILITY when read
under this repaired contract. global_sufficiency_proven=false,
llm_advantage_demonstrated=false, metrics_status=NOT_EVALUATED,
mission_goal_achieved=false and advance_m1=false always remain explicit.
Invalid reducer controls remain BLOCKED. Neither tests nor witnesses establish
forecast accuracy, LLM superiority, live data availability or scientific novelty.
