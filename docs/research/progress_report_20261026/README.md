## 数据与证据

总体比较取自 `logs/forecasting/main_comparison_20261023/` 中2026-10-24维护后的结果，包含19个基线与6个联合方法输出，共225个模型—地区—种子组合。报告使用现有冻结预测，没有新增训练或根据测试结果重新选择模型。

- `results_audit.json`：总体、地区及开发实验的结果解释。
- `latest_spike_diagnostics_*.csv`：同一批冻结预测的尖峰、常态及负价分层评分。
- `latest_spike_diagnostics_provenance.json`：225份预测的来源、哈希和评分核验。
- `latest_spike_inventory.csv`：评分单元与唯一交付小时数量。
- `baselines.json`、`baselines_academic.json`、`method.json`：原始与学术表述的内容、引用和方法来源。
- `academic_validation.json`：最终论文章节版的分页、目录、图表与版面核验。
- `archive_manifest.json`：本次归档文件的大小与SHA256，与仓库外原文件逐项核对。

## 编制材料

归档包含编制脚本、实际使用的图表与公式图片。正文保留输入权限、回顾性评估、确定性种子重复、预训练重叠和数据发布时间审计的限制，分层结果按实际价格作事后诊断。

脚本作为编制过程记录保存，部分仍引用原工作区绝对路径。原始预测文件及运行环境不随报告归档；在其他机器重建前需设置数据路径及依赖。Word编制使用python-docx，图表使用Matplotlib，目录更新与PDF导出使用LibreOffice和UNO。公式以高分辨率图片嵌入，配套保留公式源文件。

`build_academic.py` 复用 `build_report.py` 的数据和引用加载部分；最终文献修正及学术表述以已归档JSON为准。`build_baselines.py` 等早期内容生成脚本不是最终文献核对记录，直接重跑可能覆盖后续人工核查修正。
