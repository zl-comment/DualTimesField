## 6. 科学结论

1. 预声明的单变量假设完全兑现：仅把 D 的最终控制策略改为一次 final decision-only LLM turn（禁工具 + 既有 JSON Schema 结构化约束），成功率从 62/159 提升到 159/159，97 个失败全部消除，零新增失败类别。
2. 覆盖率不再是解释 D-C/D-B 的瓶颈：在全部 159 共同成功 origins 上，D-C 宏观增量为 -4.338/-2.775（D 优于 C 且幅度大于 r6 子集），D-B 为 +5.266/+1.817（仍劣于 B 但差距大幅收窄）。
3. D 的覆盖80%/90%（70.10%/84.93%）仍低于 B（80.14%/91.51%）；在 B 为当前最强基线的现状下，D 的剩余差距来自预测质量而非决策可靠性。
4. 本轮未做任何按结果的重跑、挑选、训练、拟合或调参；2023–2024 最终测试未触碰。此为 2022 开发折结果，不构成最终测试或任务完成结论；下一步须另行授权。
