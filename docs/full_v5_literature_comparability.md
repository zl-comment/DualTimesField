# V5 literature comparability statement

本文件说明 V5 结果与外部文献的可比性边界。核心原则：**当前 LightGBM 是已实现同协议 MAE/QS 强参照，不是充分调优的文献 SOTA**；任何跨协议数字不得直接对表。

## 本仓库协议（V5 沿用）

- 市场：AEMO NEM，三地区 NSW1/QLD1/TAS1（区域电价 RRP，AUD/MWh，可为负）。
- 时期：训练 2015–2021、选择 2022H1、开发（V5 新增语义）2022H2、回顾性评价 2023–2024。
- 粒度与协议：小时级、逐小时滚动 origin、72h 输入 → 24h 五分位 (0.05/0.10/0.50/0.90/0.95)；外生变量（predispatch 价格/需求/可用发电、PD PASA 备用与短缺、互联、燃气背景）带 vintage 规则（预测时已知）。
- 参数更新：评价期静态（V5 的残差库顺序更新是固定算法的状态更新，不是参数重训）。
- 指标：原始价格空间 MAE（rearranged q50）、QS = 两倍五分位平均 pinball（**CRPS 代理，非精确 CRPS**）、经验覆盖率。RMSE 报 pooled 与宏两种口径。
- 统计检验：168h 联合时间块配对 bootstrap（24h 敏感性）+ Holm 校正；origin 内 24 horizon 先平均。

## 与外部方法数字不可直接比较的原因

| 文献/方法 | 头条设置 | 与本协议的主要差异 |
|---|---|---|
| Lago et al. EPF benchmark / review（arXiv:2008.08004） | EPFT 五市场（2006–2018），日前出清、单日 24h，LEAR/DNN，rMAE+DM 检验 | 市场与年代不同；日前固定时点出清 ≠ 逐小时滚动 origin；其方法论（强简单基线、多市场、时间依赖检验）适用，数字不可比 |
| TimeXer（arXiv:2402.19072） | EPFT 数据，168h→24h，点预测 z-score MSE | 本仓库为 72h 输入、五分位、增加未来条件 token 的明确适配版（仓库内成绩 46.62 宏 MAE，落后 LightGBM） |
| PriceFM（arXiv:2508.04875） | 欧洲 38 地区预训练 MoE | 本仓库是单地区、单节点、从头训练的本地适配版，空间预训练优势不存在，不能代表完整方法 |
| TabPFN-2/3（arXiv:2609.00089） | 德国/波兰/西班牙 2021–2025 | 欧洲 market-specific 数字；NEM 协议未验证，是已登记待补的外部候选，不是既有结论 |
| NEM 深度模型 vs 波动（arXiv:2602.01157） | 同市场，价格-only、半小时级，2025H1 测试 | 信息集、粒度、测试期不同；其"深度模型难胜简单基线"与本仓库处境同构，仅作方向旁证 |
| DualTimesField 原论文（ICML 2026） | 连续时间序列重建/插值（含 Electricity 负荷数据） | **不含任何电价预测数字**；重建成绩不能为 V4/V5 预测主张背书 |
| RIS-LLM、RE-Price、TRACE 等 | 文本增强或概率生成评价 | 额外信息路线，市场/评价不同，本轮不纳入 |

## 可比性结论

1. 在"本仓库数据情形"（NEM 小时级、该信息集、该测试期）下，不存在可直接对表的文献 SOTA 数字；仓库内 LightGBM 37.10 宏 MAE（三 seed）是该设定当前已知最强参照。
2. 任何 V5 改善百分比只能表述为"相对同一冻结基线、同协议、同评价期的配对改进"，不得表述为"达到/超过文献 SOTA"。
3. 若未来需要外部锚点：EPFT 五市场复现（epftoolbox）或 TabPFN-3 本地适配是独立工作，须另立协议，不与本轮结果混合。
4. PriceFM、TimeXer 等保留"本地适配版"身份；强基线、多市场、时间依赖检验的原则参考 EPF benchmark，但其跨协议成绩不搬用。
