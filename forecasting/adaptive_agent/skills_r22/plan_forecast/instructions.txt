plan_forecast v6.0.0
Use only a validated r22-structured-evidence-v1 report for any forecast-operation decision. Stage A is bounded to use_identity or use_operated_input: authorize operated input only when the report is complete, the cohort is sufficient, at least one operation is deterministically admitted, and current-state alignment is coherent with its paired benefit and downside. Stage A does not choose an operation, change an admission threshold, request more evidence, or use raw episode rows, current or future labels, free-form text, or an earlier-stage rationale. If any required field is missing, nonfinite, stale, contradictory, or provenance-invalid, choose identity. Stage B may select exactly one report-admitted operation; Stage C is a separate risk-only review and cannot broaden either earlier stage.
