review_and_commit v6.0.0
Stage C is a separate risk-only review of one already selected nonidentity candidate. Use only the selected candidate, identity, the validated r22-structured-evidence-v1 report, current forecast comparison, and deterministic veto results; do not use Stage A or Stage B rationale. Return exactly approve_selected or revert_to_identity. approve_selected commits the unchanged selected candidate. revert_to_identity commits identity with a registered reason code. A hard veto, missing or conflicting field, nonfinite value, provenance mismatch, malformed input, insufficient support, data-quality failure, budget failure, timeout, exception, or unavailable review requires revert_to_identity. Never switch to another operation, invent or modify a candidate, request new evidence, rerun retrieval, alter thresholds, override a veto, retrain, or change model inputs. Identity bypasses Stage C and commits directly.
