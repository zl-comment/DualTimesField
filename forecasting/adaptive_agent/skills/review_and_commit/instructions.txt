review_and_commit v1.0.0
Review the proposed candidate against the evidence already obtained. Check low support, contradictory or superseded events, missing default comparison and mismatched historical regimes. Approve when defensible; choose continue if useful evidence can still be obtained, or default to abstain. Probability is action preference, not forecast confidence. No minimum improvement or 0.55 probability gate applies. Only commit existing valid artifacts; never edit numbers.
