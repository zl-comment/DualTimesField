retrieve_analogs v3.0.0
Select recent, seasonal, state or diverse retrieval from the offered actions using the current state. Returned episodes are complete mature 24-hour cases. The first selected cohort is fixed for this origin: all later input alternatives are evaluated on it. This release does not replace historical samples during a revision. Sample count and common-success support matter. Episode selection provides evaluation evidence; disconnected historical episodes are never concatenated into Chronos input.
