compare_candidates v3.0.0
Compare candidates using the latest diagnostic observation on the identical cohort and common successful episodes. Lower QS is preferable for quantile accuracy, but inspect MAE, coverage, width, support and temporal relevance as well. Historical errors are evidence, not guaranteed future errors. Never compare aggregate errors computed on different successful samples. Cached pair scores are reused on the same immutable cohort and count as reuse, not new evidence. Earlier diagnostic observations may cover fewer candidates; the latest matched result is authoritative. A large current forecast disagreement can motivate a new input configuration, but does not establish which forecast is correct. Pooling equal quantile levels is a registered heuristic, not a calibrated distribution mixture, and requires review.
