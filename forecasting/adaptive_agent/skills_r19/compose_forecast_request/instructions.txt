compose_forecast_request v2.0.0
Propose one registered frozen Chronos alternative to compare with the default LightGBM. Chronos base uses price, past demand and calendar; calendar uses price and calendar; price_only omits demand and calendar. Windows 24/48/72 are actual contiguous suffixes of the same visible history. A shorter window can focus on a recent level shift but sacrifices context; a longer window may preserve recurring structure but include an older regime. Use current state and available diagnostic evidence to choose, rather than treating more information as automatically better. Recent-fit diagnostics use at most48 context hours to predict the last24 observed hours: a72-hour main forecast is not an identical validation setting. LightGBM retains its original schema. This proposal stage tests an alternative; it does not yet select the final forecast.
