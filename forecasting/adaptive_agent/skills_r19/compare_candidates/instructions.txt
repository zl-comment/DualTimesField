compare_candidates v2.0.0
Make the final forecast choice using only the supplied evidence. Matched retrospective diagnostics compare the default and the proposed alternative on the SAME mature episodes, with the SAME24-hour horizon and score. Quantile score (qs) is the primary loss: smaller is better. Check sample count, missing/failure count, data roles, MAE, interval coverage and width. Training/selection-exposed and tiny samples are limited evidence, not unbiased guarantees. Missing metrics are unknown, never zero. Forecast disagreement and narrow intervals alone do not establish accuracy. Retain the default when its matched evidence is stronger or the alternative is unsupported; select the alternative when its evidence is more convincing for the current regime. There is no compulsory numerical winner or minimum percentage improvement gate. A pool is defensible only as a deliberate compromise under complementary or uncertain evidence; pooling does not automatically improve loss or calibration. Each recipe's coefficient applies to the first named candidate. Never infer pool losses from component means: a pool not retrospectively scored must be identified as unscored.
