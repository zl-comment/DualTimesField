# 当前主表：最新 Full_joint 与三个 seed 的基线（2026-10-24 更新）

所有当前输出均在 2023—2024 年、同三地区、同一测试起点与共同评分下汇总。每个 seed 分别评分，先做三地区等权宏平均，再报告三个 seed 的均值 ± 样本标准差；没有先平均预测。

新版 Full_joint 为平衡损失＋非对称 Anchor 尺度头，主输出采用选择期冻结的 guarded checkpoint/alpha。Full_joint_raw 使用独立按选择期 QS 选定的 checkpoint；Anchor_joint/event_off/time_shift_off 是新版 guarded 同检查点关闭干预。全部替换此前只完成 seed 2026 的旧联合模型，版本号为 asymmetric_balance_20261023。

**种子范围：**基线沿用原来的 2026/2027/2028；联合方法改变神经初始化和训练顺序，树固定 seed 2026。B_retrained 重复同一冻结树，不能视为三个独立随机训练。联合方法还使用因果成熟历史与误差，信息范围大于静态基线；这是回顾性比较，不是盲测或显著性认证。

当前表共 25 个输出、225 格，包括 15 个静态基线、4 个基础模型和联合方法的 6 个输出。旧静态 baseline_full、baseline_no_fields 的 18 格移入历史结构对照附表，不占当前主表行。连同该附表，共核验 27 个来源输出、243 格。最近四方案的 2021/2022 开发分数保留原档，不混入本表；选择最新结构不代表它已通过开发验收。

新增基础模型全部标记预训练重叠未审计：TabPFN 使用完整公共输入，其他三者使用受限输入。TabPFN 固定生产分块可重现，但旧版改变批次大小的抽样重放未通过原容差；维护版固定规范分块，原正式预测保留，未宣称全量重新重放。三种时序基础模型的 seed 重复不能解释为独立随机训练。

**数据与预算边界：**已保存的外生来源时间代理未发现晚于起点，但真实公开发布时间及后续修订审计未完成；不能声称严格实时无泄露。当前为固定配置比较，未执行各模型等预算HPO。维护证据及 TimesFM 开发选择见[基线维护档案](../baseline_maintenance_20261024/README.md)。

TimesFM 当前仍引用原 ridge0 正式结果；未完成开发门槛和九格审计的候选不会替换主表。
